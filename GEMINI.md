# Project Rules & Communication Protocol

## 1. Questions vs. Action Directives
- **NEVER start working, editing code, or implementing features when the user asks a question** (specifically any prompt ending with a `?` or asking for an explanation/idea like "did you...", "can we...", "what is...", "how does...").
- A question is strictly for getting an idea or understanding current behavior—it is **NOT** a command to write code or make changes.
- In response to questions, **only explain the idea or answer the question directly in text**.
- **Wait for explicit instruction or confirmation from the user** (e.g., "implement this", "go ahead and do it", "apply this change") before editing any files or writing code.
